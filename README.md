\## 4. 数据与预处理



分类实验采用sklearn内置的Iris鸢尾花数据集。

首次运行时将其保存为CSV，之后从CSV读取。



数据包含150个样本、4个数值特征、3个类别，

每类50个样本，无缺失值。



4个特征为：

花萼长度、花萼宽度、花瓣长度、花瓣宽度。



采用分层随机划分：

训练集105条，测试集45条，随机种子固定为42。



使用Z-score标准化：

标准化值 =（原始值 - 训练均值）/ 训练标准差。



测试集使用训练集的均值和标准差；

交叉验证中，每一折也只使用该折训练部分计算标准化参数。



\## 5. 手写算法流程



1\. fit保存训练样本和标签。

2\. 计算待测样本与训练样本的距离。

3\. 对距离排序，取最近的k个邻居。

4\. 分类时由邻居多数投票。

5\. 回归时取邻居目标值的平均数。



支持欧氏距离和曼哈顿距离。

分类投票平局时，在并列类别中选择最近邻所属类别。

邻居距离相同时，保留训练样本原始顺序。



分类核心没有调用sklearn的KNN算法。



\## 6. k值选择



在训练集内部进行5折分层交叉验证。

候选k为1、3、5、7、9、11、13、15。



选择平均验证准确率最高的k；

完全相同时，选择候选列表中较小的k。

测试集不参与k值选择。



\- 选出的k：7

\- 对应平均验证准确率：93.33%

详细结果见results/k\_cv\_scores.csv和k\_accuracy.png。

\## 8. 性能比较



在相同的45个测试样本和105个训练样本上，

比较循环版与向量化版欧氏距离函数。



计时前先校验两种实现结果一致。

每组运行20次，共5组，取组耗时中位数并换算为单次耗时。



\- 循环版单次耗时：4.65272 ms

\- 向量化版单次耗时： 0.053315 ms

\- 循环版耗时/向量化版耗时：87.27



结果只代表本机、本次数据规模下的距离计算耗时，

不包含排序、投票等步骤。

向量化会使用额外的中间数组内存。



\## 9. 进阶回归实验



使用固定随机种子生成80条模拟数据：

y约等于2x，并加入随机误差。



训练集64条，测试集16条。

固定k=5，使用近邻目标值均值预测。



\- 测试集MAE：0.8722

\- 测试集MSE：1.0037



MAE和MSE越小，数值预测误差越小。

本实验展示回归流程，没有对回归k值进行优化。
